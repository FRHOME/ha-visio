# HA Visio

Appel vidéo d'un clic vers une tablette murale, directement dans Home Assistant : pas d'app à installer, pas de compte. L'image et le son passent en pair-à-pair (WebRTC) ; l'app ne fait que la mise en relation et pilote la tablette (Kiosk Satellite ou tout navigateur kiosque pilotable par un service HA).

## Installation

1. **Paramètres → Modules complémentaires → Boutique → ⋮ → Dépôts**, ajoute `https://github.com/CHANGE_ME/ha-visio`.
2. Installe **Visio**, règle l'onglet *Configuration*, démarre-la et coche **Afficher dans la barre latérale**.

Détails : [visio/DOCS.md](visio/DOCS.md).
